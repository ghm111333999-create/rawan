# Asset Replacement Guide

Drop your personal files into these folders and update `/src/config/romanticConfig.ts`:

- `/public/images/memories/` — Personal photographs (e.g. `our-favorite.jpg`, referenced as `/images/memories/our-favorite.jpg`)
- `/public/images/illustrations/` — Custom illustrations
- `/public/images/flowers/` — Custom floral accents
- `/public/music/romantic-piano.mp3` — Background romantic piano audio track (falls back gracefully to a gentle built-in Web Audio piano melody if not provided)
